# Infiniview Docs

- Dedicated public product docs for Infiniview. User-facing docs should live here, not in `../infiniview` or `../infiniview-web-frontend`.
- Stack: Next.js App Router, TypeScript, Tailwind CSS v4, pnpm. `pnpm dev` uses Turbopack by default.
- Theme must match `../infiniview-web-frontend`: dark `#07080b`, lime `#d2fb5a`, Inter Tight, JetBrains Mono, square logo mark, grid background, mono section labels, restrained bordered panels.
- Keep docs aligned with `../infiniview` source behavior, especially dashboard routes, GitHub automation, scan config, findings, exports, suppressions, readiness, compare/trust, secrets, and API contracts.
